## English

A highly optimized, dynamic portfolio and lead-generation backend built using **Django (Python)**. This project serves as a live engineering showcase, demonstrating clean code architecture, secure database management, and third-party API integrations.

### 🛠️ Tech Stack & Key Features
- **Backend Core:** Django & Django REST Framework (Python)
- **Integration:** Automated SMS Notification System via Iranian SMS Gateway Providers (Pattern-based REST API)
- **Database:** Fully optimized model layers with PostgreSQL / SQLite support
- **Architecture:** Modular, secure, and clean structure based on software engineering best practices

### 📦 Project Structure
The repository is split into distinct, decoupled applications:
- `core/`: Main configuration, security, and environment settings.
- `projects/`: Dynamic portfolio and dynamic project showcase engine.
- `contact/`: Advanced lead capturing form with integrated automated SMS alerts.

### 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/yourusername/ramtin-portfolio.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Apply migrations: `python manage.py migrate`
4. Run the server: `python manage.py runserver`

## فارسی

یک موتور پورتفولیوی پویا و سیستم بهینه‌سازی‌شده برای جذب کارفرما که با فریم‌ورک **جنگو (پایتون)** توسعه یافته است. این پروژه به عنوان یک نمونه‌کار زنده مهندسی، بازتاب‌دهنده ساختار کدنوسی تمیز، مدیریت امن پایگاه‌داده و اتصال به سرویس‌های جانبی (API) است.

### 🛠️ ابزارها و ویژگی‌های کلیدی
- **هسته بک‌اند:** جنگو و فریم‌ورک پورتفولیوی REST (Django REST Framework)
- **اتصال به سرویس‌ها:** سیستم اطلاع‌رسانی خودکار و آنی پیامکی از طریق پنل‌های بومی (ارسال بر اساس پترن/الگو)
- **پایگاه داده:** لایه‌های مدل کاملاً بهینه‌سازی‌شده با پشتیبانی از PostgreSQL / SQLite
- **معماری:** ساختار ماژولار، امن و استاندارد بر اساس اصول مهندسی نرم‌افزار (Clean Code)

### 📦 ساختار پروژه
این ریپازیتوری به برنامه‌های تفکیک‌شده و مستقل (Decoupled) تقسیم شده است:
- `core/`: تنظیمات اصلی پروژه، مدیریت متغیرهای محیطی و امنیت.
- `projects/`: موتور داینامیک نمایش نمونه‌کارها و پروژه‌ها.
- `contact/`: فرم پیشرفته ثبت درخواست پروژه همراه با سیستم هوشمند ارسال پیامک به توسعه‌دهنده.
